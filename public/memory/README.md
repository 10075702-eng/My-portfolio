# 余忆 · What Remains

周俊行的互动影像作品第一版。全景、视频和现场声音复用现有泰晤士河素材；独立于《明信片之外》。

## 体验

进入后拖动全景。停留在小船、桥或分河附近，景物会逐渐清晰；直接点清晰的景物进入视频。看过至少一秒的视频会留下痕迹，痕迹随继续探索缓慢淡去。观看视频或打开说明时暂停遗忘。可以随时用“留下此刻”导出包含当前清晰度的 PNG。

方向键转动，回车进入当前清晰片段。手机支持拖动、轻点和双指缩放。“如何探索”提供可访问的片段定位入口。“轻柔模式”减弱模糊和转场，自动尊重系统减少动态效果设置。中英文可切换。

## 素材与空间

全景：`/r2/postcard/pano/scene-a-riverside.jpg`。视频：`thames-boat.mp4`、`thames-bridge.mp4`、`thames-canal.mp4`，同一 `/r2/postcard/video/` 目录。全部采用现有同源代理，不重新上传原片。

小船定位采用前作用户校正角度 -72° / -1°。桥 74° / -2°，分河 62° / -4°。分河、小船的细节机位与全景不同，因此以淡入记忆片段连接，不模拟无缝空间推进。模糊和像素化仅为显示效果，原始素材保持完整。

## 本地预览

在本项目上级目录运行 `node outputs/memory-server.cjs`，打开 http://127.0.0.1:4178/memory/ 。素材需要联网。发布时将 memory 文件夹放入作品集 public 目录；复用该站现有 /r2 代理和 /postcard 封面。

## 创作说明

以注意力唤回清晰，以离开表现消散。清晰区域固定在球面景物位置；使用平滑的角距离蒙版、模糊采样和稳定像素网格。动态统一由一个渲染循环驱动，避免多个动画争用状态。没有评分、倒计时或必须全部收集的要求。
